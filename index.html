MÁS SIMPLE
Sin conectar
1
Entrá a supabase.com, creá una cuenta gratuita y un nuevo proyecto.
2
En tu proyecto, andá a Settings → API. Copiá la Project URL y la clave anon public.
3
Pegá los datos abajo y tocá Conectar. Si es la primera vez, te mostramos el SQL para crear las tablas.
🔐 Tu anon key es segura para usar en el frontend.
⚠️ Primera vez: ejecutá el SQL que te mostramos en Supabase → SQL Editor para crear las tablas y habilitar el acceso.
💾 Tablas: clientes, cuentas y perfiles.
Sin conectar
1
Abrí un Google Sheets nuevo. Andá a Extensiones → Apps Script y pegá el contenido del archivo code.gs que descargaste.
2
Hacé clic en Implementar → Nueva implementación → Aplicación web. Ejecutar como: Yo. Acceso: Cualquier persona. Copiá la URL.
3
Pegá la URL abajo (termina en /exec) y conectá.
⚠️ Con Google Sheets el acceso es "Cualquier persona" — quien tenga la URL puede ver los datos.
✅ Para uso personal o de confianza está bien. Si querés más seguridad, usá Supabase.
