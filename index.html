MÁS SIMPLE
Sin conectar
1
Entrá a supabase.com, creá una cuenta gratuita y un nuevo proyecto.
2
En tu proyecto → Settings → API. Copiá la Project URL y la clave anon public.
3
Pegá abajo y conectá. Si es la primera vez, te mostramos el SQL para crear las tablas.
🔐 Tu anon key es segura en el frontend.
⚠️ Primera vez: ejecutá el SQL en Supabase → SQL Editor.
Sin conectar
1
Abrí un Google Sheets → Extensiones → Apps Script → pegá el código del code.gs.
2
Implementar → Nueva implementación → Aplicación web. Ejecutar como: Yo. Acceso: Cualquier persona.
3
Pegá la URL abajo (termina en /exec) y conectá.
⚠️ Acceso "Cualquier persona" — quien tenga la URL puede ver los datos. Para más seguridad usá Supabase.
